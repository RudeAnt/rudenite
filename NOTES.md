## Текущий этап
**M2 проверен, хитстоп-кривая проверена.** Вариант B, шаг 1: движение без блокировки при ударе (множитель скорости по фазам, инерция, рывок) — ждёт проверки. Шаг 2 — план M2.5 «реакции босса» (перед M3). Дальше — M3: guard/парри/posture (захват — непарируемый).

## Стек (закреплено)
phaser 3.90.0, vite 7.3.8, typescript 5.9.3. Node >= 20.19. Запуск: `npm install`, `npm run dev`. Проверка типов + сборка: `npm run build`.

## Принятые решения
- Логика в плоских мировых координатах; изометрия только в `src/world/iso.ts` (worldToScreen / screenToWorld / screenDirToWorld).
- Два уровня времени в `scene.ts`: реальные кадры 60 Гц через аккумулятор мс (`update` → `realTick`, учитывает F2), кадры логики целые через накопитель дробных кадров (`realTick` добавляет масштаб времени, `tick` при накопителе >= 1). Когда кривая хитстопа кончилась, дробный остаток переносится в аккумулятор мс. Отрисовка интерполирует позицию между кадрами логики (prevX/prevY), доля = накопитель + дробь реального кадра × масштаб. Debug-хитбоксы рисуются по реальной позиции логики.
- Движение с инерцией: скорость тянется к желаемой с `player.accel` (разгон) / `player.decel` (торможение). Во время удара максимальная скорость умножается на `attack.moveScale[фаза]`, в оцепенении — 0 (только торможение). Упор в стену гасит скорость по этой оси. Всё в кадрах логики — хитстоп-замедление замедляет и инерцию.
- Рывок удара (`attack.lunge`): начинается за `lead` кадров до конца startup, `frames` кадров, линейное затухание, суммарно `distance`, по зафиксированному направлению удара. Отдельно от инерции — не оставляет остаточной скорости.
- WASD — относительно ЭКРАНА (W = вверх по экрану), вектор переводится в мир. Скорость постоянна в мире, поэтому на экране бег по вертикали выглядит вдвое медленнее, чем по горизонтали (честная изометрия).
- Секторы прицела считаются в мире; сектор 0 центрирован на мировой оси +X. При N=4 границы секторов на экране — ровно вертикаль и горизонталь через игрока (сектор = экранная четверть: 0 низ-право, 1 низ-лево, 2 верх-лево, 3 верх-право).
- Автомат игрока: `state` + `stateFrame` в `player.ts`, переходы в `switch`. idle/move/attack/hurt/dead (idle/move — только метка, бег работает во всех живых состояниях); атака = startup→active→recovery (фазы считаются по `stateFrame`, 0 — кадр входа). Направление удара фиксируется в момент начала атаки.
- Буфер ввода (`ActionBuffer` в `input.ts`): события Phaser копятся между тиками, на тике переходят в буфер и живут `input.bufferFrames` кадров, пока автомат их не заберёт (`consume`). Несколько нажатий одного действия за тик = одно. Пока подключена только ПКМ (attack); ЛКМ/пробел — в M3/M4.
- Хитстоп = глобальная кривая масштаба времени (`src/hitslow.ts`): `scale = 1 − (1 − minScale)·sin^power(π(i+0.5)/frames)` на i-м реальном кадре — плавно вниз, минимум, плавно обратно. Отдельные параметры для удара по боссу и по игроку (`combat.hitSlow*`). Новое попадание перезапускает кривую; если в одном кадре оба попадания — берётся кривая удара по игроку. «Потерянное время» Σ(1 − scale) и текущий масштаб — в F1. Буфер нажатий стареет в реальных кадрах, замедление его не растягивает.
- Проверки config при старте — `checkConfig()` в `boss.ts` (posture, chaseSpeed < player.speed).
- Posture: удар игрока даёт `postureDamage`, регенерация через `postureRegenDelay` кадров без урона. Инвариант: спам ударов не заполняет шкалу — `checkPostureBalance()` пишет предупреждение в консоль, если config его нарушает. Полная шкала пока просто упирается в максимум (оглушение — M3).
- Коллизия тел: только в `combat.ts` — выталкивание игрока по линии центров; если игрок упёрся в стену, остаток перекрытия снимается сдвигом босса. Попадание: зона (сектор / полоса / круг) vs круг цели.
- Атаки босса — данные: `BOSS_ATTACKS` в `config.ts`. Атака = вес, `engage` (дистанция начала), список шагов (комбо). Шаг = тип, сторона (для directional), форма зоны, кадры telegraph/track/active/recovery, урон. Добавить атаку = добавить запись, код не трогать.
- Автомат босса: idle (пауза `idleFrames`) → выбор атаки → chase (до `engage`) → по шагам telegraph → active → recovery → idle. Попадание игрока по боссу — только вспышка (`flash`), атаку не прерывает. Один шаг попадает максимум один раз.
- Доворот: в idle/chase и первые `track` кадров телеграфа босс поворачивается к игроку не быстрее `turnSpeed`; дальше направление зафиксировано (контур телеграфа становится ярким).
- Выбор атаки: случайно по весам, одна атака не больше `maxRepeat` раз подряд.
- Клин верного сектора у игрока можно скрыть: `view.showGuardSector = false` (стрелка остаётся).
- Захват (grab) — просто урон, без удержания и броска; в M3 непарируемый.
- Верный сектор направленного удара = угол на босса ± `sideOffset` (left: −, right: +, мир «y вниз»). Считается по текущим позициям, т.е. меняется, если игрок обходит босса во время телеграфа. Пока только показывается (оверлей + клин/стрелка); проверка guard — M3.
- Игрок: HP, попадание босса → `hurt` (оцепенение `staggerFrames`, прерывает удар) или `dead`. Хитстоп при попадании по игроку — `combat.hitSlowBossHitsPlayer`.
- Рестарт (R) — сброс состояния арены без перезапуска сцены (слушатели ввода не дублируются).
- Тела рисуются в порядке экранного Y.
- Вся отрисовка — один Graphics, перерисовывается каждый кадр; пол — отдельный статичный Graphics.
- Управление: WASD бег, ПКМ удар (направление — курсор), ЛКМ guard (M3), пробел dodge (M4). Контекстное меню браузера подавлено — иначе ПКМ его открывает, а оно съедает keyup и WASD залипает.
- Debug-клавиши: F1 оверлей, F2 slow-mo, F3 пауза, F4 — один реальный кадр (на паузе; во время хитстопа кадр логики может не сдвинуться). Только при F1: G — бессмертие игрока (попадания, вспышка и оцепенение есть, HP не убывает; пока включено, в подсказке видно [БЕССМЕРТИЕ]), 1–6 — следующая атака босса.
- Цвета и размеры отрисовки тоже в config (`view`), отдельно от боевых чисел.

## Файлы
- `src/config.ts` — все числа
- `src/world/iso.ts` — проекция
- `src/input.ts` — снимок ввода на кадр логики (в мире)
- `src/player.ts` — автомат и движение игрока
- `src/boss.ts` — автомат босса (idle/chase/telegraph/active/recovery/dead), выбор атаки, HP, posture
- `src/combat.ts` — коллизия тел, зоны попаданий, верный сектор
- `src/draw.ts` — отрисовка зон и стрелок на полу (общая для сцены и debug)
- `src/debug.ts` — оверлей, slow-mo, пауза/шаг
- `src/hitslow.ts` — кривая хитстопа и расчёт потерянного времени
- `src/scene.ts` — цикл: реальные кадры + кадры логики, хитстоп, камера, отрисовка, HUD, рестарт
- `src/main.ts` — запуск Phaser

## Известные проблемы
- (решено в M1) буферизация нажатий по кадрам логики.
- Нажатие, сделанное раньше чем за `bufferFrames` до конца удара, истекает (например, клик сразу после попадания). Так задумано, но если цепочка ударов ощущается «глухой», надо поднять `input.bufferFrames`.
